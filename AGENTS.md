# Comandos para Agenda 2026

## Execução
- `python app.py` - Iniciar a aplicação Flask (http://localhost:5000)
- `AGENDA_PORT=5001 python app.py` - Iniciar em porta personalizada

## Verificação
- `python -m py_compile app.py` - Verificar sintaxe Python

## Dependências
- `pip install -r requirements.txt` - Instalar dependências
